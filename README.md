
# Reliance Retail – Financial Accounting & Analysis (FY 2025–26)

## Project Overview
A practical financial accounting project covering the accounting cycle, GST workings, bank reconciliation, inventory management, financial statements, and dashboard preparation using Microsoft Excel.

## Key Activities
- Chart of Accounts and Journal Entries
- Ledger Posting and Trial Balance
- Accounts Receivable and Accounts Payable
- Bank Reconciliation Statement (BRS)
- Inventory Management and COGS Calculation
- Monthly GST Workings
- Payroll and Month-End Adjustments
- Monthly Profit & Loss and Balance Sheet
- Annual Financial Reports and Dashboard

## Key Learnings
- Practical accounting cycle and bookkeeping.
- Bank reconciliation and working capital management.
- GST calculations and inventory valuation.
- Financial statement preparation.
- Excel-based financial analysis and reporting.
